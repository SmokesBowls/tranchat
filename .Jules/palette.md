## 2024-03-09 - Icon-Only Button Accessibility Pattern
**Learning:** Across the application's components (JoinRoom, SetPassword, Room), there is a consistent pattern of using absolute-positioned, icon-only `<button>` elements (e.g., back and exit buttons) containing purely decorative SVGs. These buttons lacked `aria-label` attributes, tooltip `title`s, keyboard focus visibility (`focus-visible` styles), and `aria-hidden="true"` on their inner SVGs. This makes navigation significantly harder for screen reader and keyboard-only users.
**Action:** When introducing new UI components with icon-only actions, standardise the approach by always adding `aria-label`, a corresponding `title` tooltip, specific `focus-visible:ring-2 focus:outline-none` classes, and ensuring the inner `<svg>` is explicitly hidden from assistive technologies using `aria-hidden="true"`.
