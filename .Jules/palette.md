## 2024-04-02 - Missing A11y on Icon-Only Navigation Buttons
**Learning:** Found a recurring pattern in this app's components (`Room.jsx`, `JoinRoom.jsx`, `SetPassword.jsx`) where icon-only navigation buttons (back/exit) lack essential accessibility attributes like `aria-label`, `title`, and keyboard focus visibility (`focus-visible:ring-*`). Additionally, purely decorative SVGs inside these buttons are missing `aria-hidden="true"`. Screen reader users and keyboard navigators would have significant trouble identifying and interacting with these critical navigation controls.
**Action:** When creating or reviewing icon-only buttons, consistently apply `aria-label`, `title` (for mouse hover tooltips), keyboard focus rings (e.g., `focus:outline-none focus-visible:ring-2 focus-visible:ring-blue-500 rounded`), and `aria-hidden="true"` on the inner SVG element.
