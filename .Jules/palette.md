## 2024-04-07 - Icon-Only Button Accessibility Pattern\n**Learning:** Icon-only buttons frequently omit semantic descriptors and focus indicators, particularly in React components using Tailwind. SVGs inside these buttons are also incorrectly read by screen readers unless hidden.\n**Action:** Always add `aria-label`, `title`, `focus-visible` utility classes (using `ring-blue-500` for standard and `ring-white` for dark overlays), and `aria-hidden="true"` to child SVGs for all icon-only interactive elements.
