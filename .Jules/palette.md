## 2024-05-24 - Accessibility for Icon-Only Buttons
**Learning:** This app frequently uses icon-only buttons (e.g., Back and Exit buttons in overlays). These often lack proper `aria-label`, `title`, keyboard focus states, and decorative `aria-hidden` attributes on the SVG. Different contexts require different focus ring colors (e.g., standard light backgrounds need `focus-visible:ring-blue-500` to match the app's primary theme color, while buttons on dark overlay backgrounds need `focus-visible:ring-white`).
**Action:** When creating or updating icon-only buttons, always explicitly provide `aria-label` and `title`. Add `focus-visible` classes with context-appropriate colors (`ring-blue-500` for light, `ring-white` for dark/overlay). Ensure inner SVG icons have `aria-hidden="true"`.
